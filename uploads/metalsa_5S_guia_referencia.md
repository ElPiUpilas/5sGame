## 2. Course Structure (Sequence)

Both guides follow the same 5-section structure in the same order:

1. **Introduction**
2. **Knowing the 5S Methodology** *(background + definition + objectives)*
3. **5S Stages** *(one stage at a time: Sort → Set in Order → Shine → Standardize → Sustain)*
4. **5S in Metalsa** *(application, layout, resistance to change, benefits)*
5. **Conclusion**

This sequence is consistent across both versions and should be preserved in the app.

## 4. Core Definition (Canonical Wording)

## 5. Background / Origin Story

Both guides state the same three facts:
- The methodology started in **Japan in the 60's**
- It is **not exclusive of a culture or country**
- It represents **universal principles** and has been adopted across different industries

## 6. The 5S — Official Terminology Table

This table appears in both guides and defines the canonical vocabulary:

| # | Japanese | English Term | Definition |
|---|---|---|---|
| 1 | SEIRI | **SORT** | Distinguish between necessary and unnecessary items in order to decide which will be discarded. |
| 2 | SEITON | **SET IN ORDER** | Arrange all items remaining after SEIRI in an orderly manner. |
| 3 | SEISO | **SHINE** | Keep machines and work environment clean. |
| 4 | SHITSUKE | **STANDARDIZE** | Build in self-discipline and make a habit of engaging in 5S by establishing standards. |
| 5 | SEIKETSU | **SUSTAIN** | Extend the concept of cleanliness and continuously practice the above three steps. |

> ⚠️ **Note:** S4 and S5 are swapped in mnemonic order vs. alphabetical (SHITSUKE=Standardize, SEIKETSU=Sustain). Both guides are consistent on this mapping — the app must preserve it exactly.

## 7. Objectives of 5S (Both Guides — Identical)

Both guides list the same four objectives:
1. Make waste visible and help to eliminate it.
2. Create a culture of **continuous improvement**.
3. Create a culture of **cleanliness and discipline**.
4. Create a **safe space** to work.

## 10. 5S in Metalsa — Application Model

Both guides describe the same operational implementation:

- All common areas are **delimited on a Layout**
- Each area has a **responsible assigned** who prepares an implementation and follow-up plan
- **Audits** on the plant check implementation in all areas
- **Self-audits** applied every month
- **Random audits** validate accuracy of scores

> The term "Lay-out" (with hyphen) is used in both guides for the area delimitation document.

## 12. Resistance to Change (Both Guides — Identical)

Four common resistance phrases presented to participants:
1. "Why should I clean if everything gets dirty again?"
2. "Applying 5S will not increase productivity"
3. "We do have a lot of work, so there is no time for 5S"
4. "We have tried to implement 5S and it has not worked"

## 13. Pedagogical Methods Used

Both guides use the same teaching strategies in the same sequence:

| Method | Description |
|---|---|
| **Introductory Lego activity** | Participants build trucks without organization (baseline experience) |
| **Discussion questions** | "Did you complete your activity? Did you have any complication?" |
| **Concept introduction** | Definition, background, objectives |
| **Classroom activity** | Classify objects as necessary/unnecessary (adapted per context) |
| **Lego practice per S** | Apply each S concept to the physical exercise |
| **Reflection questions** | "What benefits did you find? How does this apply to your work?" |
| **Closure Lego activity** | Repeat truck-building with 5S applied — compare results |
